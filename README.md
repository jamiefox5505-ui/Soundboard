# Soundboard

A playful, responsive meme-inspired soundboard with 1,000 searchable pads, category filters, favorites, recently played sounds, volume control, and browser-generated audio previews.

## Run it

Open `index.html` in a modern browser. No build step or dependencies are required. The Web Audio API creates the previews locally in your browser.

## Features

- 1,000 pads across 10 categories
- Instant search, sorting, category and duration filters
- Favorites and recent plays saved in local storage
- Responsive layout, keyboard shortcuts (`/` to search, `Space` to play)
- Audio previews synthesized with the Web Audio API

> The pads are playful, generated audio previews—not original recordings of memes, creators, shows, or games. Add audio files you have permission to use if you want to ship original sound clips.
